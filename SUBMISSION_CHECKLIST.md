## ✅ Stage 3: Trained Classifier for Win-Probability

**Status:** COMPLETE and VERIFIED

**What was done:**
- Logistic regression classifier trained on 60 non-holdout disputes
- 18 features: one-hot reason codes + binary/normalized evidence fields
- 500 iterations, L2 regularization (λ=0.01)
- Rule-weighted baseline retained as `baseline_rule` for comparison
- Both models score all disputes via `/api/score-all`
- `model_version` column in `scores` table tracks which model produced each score
- Feature importances (coefficient × feature value) feed the "Score factors" UI

**Verification:**
- ✅ All 80 disputes scored with both models
- ✅ All 20 holdout disputes have both `baseline_rule` and `trained_v1` scores
- ✅ `/metrics` page displays side-by-side comparison (precision/recall/F1)
- ✅ Confusion matrices and cost analysis visible

**Stop condition met:** Side-by-side metrics table shows both models on holdout data. Feature importances render in Score factors UI.

## 📋 Submission Summary

**What this system does:**
A defense-only chargeback evidence management tool that:
1. Retrieves evidence from multiple categories (auth, fulfillment, behavioral, communication)
2. Scores win probability using BOTH a trained ML classifier and a rule-weighted baseline
3. Generates persuasive dispute response narratives grounded to available evidence
4. Explicitly labels missing evidence (never fabricates or infers)
5. Provides full audit trail of every action
6. Never auto-submits — analyst must copy draft manually

**Technical highlights:**
- Real Razorpay test-mode orders via API (not just mocked data)
- Trained logistic regression outperforms rule-based baseline on holdout set
- Gemini Pro generates context-aware narratives from structured evidence
- 80 synthetic disputes (60 train / 20 holdout) with 30% deliberate missing data
- SQLite database with full audit log (append-only)

**Defense-only proof:**
- No submission endpoint exists in the codebase
- No outbound communication (email/SMS/webhook)
- Missing evidence explicitly labeled, never filled with guesses
- "Mark reviewed" is the only state-changing action
